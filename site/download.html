Install and get started

  1. Quit any running copy

    Choose Quit Pulse from the tray so the single-instance lock does not reactivate an older build.

  2. Run the EXE to install for your user account

    Choose an installation directory. Unsigned builds may trigger a Windows publisher warning. Verify the source and checksums; do not disable system security protections.

  3. Start Pulse and select Live

    Live shows VS Code and Claude Code sessions together. Use the Agent filter to narrow the list. Claude monitoring requires a separately installed Claude CLI; no additional editor extension is needed. Demo remains separate sample data.

Current support

Windows x64, local VS Code / GitHub Copilot and Claude Code session snapshots. Development builds add source-path settings and opt-in Claude hooks; the original v0.1.0 installer does not include these additions. Session actions currently open Pulse details. Returning to the matching application's input window is the next priority. Remote workspaces, other architectures and Codex are not supported yet.
