Install and get started

  1. Quit any running copy

    Choose Quit Pulse from the tray so the single-instance lock does not reactivate an older build.

  2. Run the EXE to install for your user account

    Choose an installation directory. Unsigned builds may trigger a Windows publisher warning. Verify the source and checksums; do not disable system security protections.

  3. Install Companion and open your project

    In VS Code, run Extensions: Install from VSIX and select the downloaded extension. After updating an active extension, run Developer: Reload Window.

  4. Start Pulse and select Live

    Live shows VS Code and Claude Code sessions together. Use the Agent filter to narrow the list. Claude monitoring requires a separately installed Claude CLI. Demo remains separate sample data.

Current support

Windows x64, local VS Code / GitHub Copilot and Claude Code session snapshots. Claude per-turn hooks and original-terminal navigation are not connected yet. Provider formats may change between versions. Remote workspaces, other architectures and Codex are not supported yet.
